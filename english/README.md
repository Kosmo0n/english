# 📚 Ағылшын тілін үйрену платформасы

Школьников 7–9 классов үшін интерактивті веб-сайт

---

## 🎯 Мақсаты

Бұл платформа оқушыларға ағылшын тілін ойындар арқылы, интерактивті тапсырмалар және квиз пішінінде үйретеді.

### Ерекшеліктері:
✅ Казахский интерфейс  
✅ Минималистичный, современный дизайн  
✅ Адаптивность на все устройства  
✅ Интерактивные квизы с обратной связью  
✅ Отслеживание прогресса (LocalStorage)  
✅ 18 тем (6 тем × 3 класса)  
✅ Объяснения грамматики на казахском  
✅ Без зависимостей (чистый HTML/CSS/JS)

## 🚀 Быстрый старт

### Способ 1: Прямое открытие в браузере

1. **Скачать/скопировать проект**
2. **Открыть `index.html` в браузере** (двойной клик или перетащить в браузер)
3. **Готово!** Приложение готово к использованию

### Способ 2: Запуск с локального сервера (рекомендуется)

Если вы используете Python 3:
```bash
cd gitkos
python -m http.server 8000
```

Затем откройте в браузере: `http://localhost:8000`

Если у вас Node.js:
```bash
npx http-server gitkos
```

Затем откройте в браузере: `http://localhost:8080`

## 📖 Структура сайта

### 1️⃣ **Главная страница** (`/index.html`)
- Заголовок: "Ағылшын тілін үйрену платформасы"
- Кнопки: "Бастау", "Сыныпты таңдау"

  - Present Simple
  - Present Continuous
  - Past Simple
  - Future Forms
  - Comparatives & Superlatives
  - Modal Verbs
- Каждая тема:
  - Краткое объяснение на казахском
  - Примеры с переводом
  - Структура использования

  - Выбор правильного ответа

  - Матчинг
  - Общие вопросы
- Функции:
  - Прогресс-бар
  - Обратная связь (правильно/неправильно)
  - Объяснения ответов
  - Подсчет баллов
  - Результаты (%)

### 6️⃣ **Прогресс** (`/progress`)
- Общая статистика:
  - Завершенные темы
  - Всего тем
  - Средний балл
- Прогресс по классам
- Слабые места (область для повторения)

## 💾 Сохранение прогресса

Все данные о прогрессе сохраняются в **localStorage**:

```javascript
// Структура данных в браузере
{
  completedTopics: {
    'daily-routines': true,
    'school-life': true,
    ...
  },
  quizResults: [
    {
      topic: 'daily-routines',
      class: 7,
      percentage: 85,
      correct: 4,
      total: 5,
      date: 1717753200000
    }
  ],
  weakAreas: ['environment', 'technology']
}
```

### Функции прогресса:
- Отслеживание выполненных тем
- История результатов квизов
- Определение слабых мест (% < 60)
- Средняя оценка по всем квизам

## 🔧 Кастомизация

### Добавить новую тему

В файле `js/data/topics.js`:
```javascript
TOPICS[7].push({
    id: 'my-topic',
    title: 'My Topic',
    description: 'Description',
    icon: '📚',
    lessons: ['Lesson 1', 'Lesson 2']
});
```

### Добавить новый квиз

В файле `js/data/quizzes.js`:
```javascript
QUIZZES['my-topic'] = {
    title: 'My Quiz',
    questions: [
        {
            id: 1,
            question: 'Question text?',
            questionKz: 'Сұрау тексі?',
            options: [
                { text: 'Option 1', textKz: 'Опция 1' },
                { text: 'Option 2', textKz: 'Опция 2' }
            ],
            correct: 0,
            explanation: 'Explanation text'
        }
    ]
};
```

### Изменить цвета

В файле `css/styles.css`, изменить переменные `:root`:
```css
:root {
    --primary: #YourColor;
    --accent: #YourColor;
    /* ... */
}
```

## 🐛 Troubleshooting

### Приложение не загружается
- Проверьте, что все файлы в правильной структуре
- Убедитесь, что все пути к скриптам правильные
- Откройте консоль браузера (F12) для ошибок

### Квизы не работают
- Проверьте файлы в `/js/data/`
- Убедитесь, что квиз имеет правильный ID темы

### Прогресс не сохраняется
- Проверьте, включено ли локальное хранилище в браузере
- Попробуйте другой браузер (приватный режим может не сохранять данные)
