## 🔧 Типичные проблемы

### Проблема: Сайт не открывается
**Решение:**
1. Убедитесь что файл `index.html` находится в папке `gitkos`
2. Попробуйте открыть прямо файл через браузер
3. Проверьте консоль браузера (F12) на ошибки

### Проблема: Стили не загружаются
**Решение:**
1. Проверьте что папка `css` существует
2. Убедитесь что `styles.css` в папке `css`
3. Перезагрузите браузер (Ctrl+F5)

### Проблема: Квизы не работают
**Решение:**
1. Проверьте что папка `js/data` имеет файлы:
   - `topics.js`
   - `grammar.js`
   - `quizzes.js`
2. Откройте консоль браузера (F12) и проверьте ошибки
3. Перезагрузите страницу

### Проблема: Прогресс не сохраняется
**Решение:**
1. Убедитесь что браузер поддерживает LocalStorage
2. Проверьте что вы не в приватном режиме
3. Попробуйте другой браузер

## 💾 Данные и сохранение

### Где хранятся данные?
Все данные о прогрессе сохраняются в **LocalStorage браузера** (на вашем устройстве):
- Нет отправки на сервер
- Полная приватность
- Данные не удаляются автоматически

### Как просмотреть данные?
1. Откройте консоль браузера (F12)
2. Перейдите на вкладку **Application**
3. Нажмите **Local Storage** > текущий адрес
4. Найдите ключ `english_learning_progress`

### Как экспортировать данные?
```javascript
// Откройте консоль и выполните:
JSON.stringify(JSON.parse(localStorage.getItem('english_learning_progress')), null, 2)
```

### Как удалить все данные?
```javascript
// Откройте консоль и выполните:
localStorage.removeItem('english_learning_progress')
```

## 🎨 Кастомизация

### Изменить цвета
Отредактируйте файл `css/styles.css`:
```css
:root {
    --primary: #56ab91;      /* Основной цвет */
    --accent: #52b788;       /* Дополнительный цвет */
    --primary-dark: #2d6a4f; /* Тёмный цвет */
}
```

### Добавить новую тему
1. Откройте `js/data/topics.js`
2. Добавьте новую тему в нужный класс:
```javascript
{
    id: 'my-topic',
    title: 'My Topic',
    description: 'Description',
    icon: '📚',
    lessons: ['Lesson 1']
}
```

### Добавить квиз для темы
1. Откройте `js/data/quizzes.js`
2. Добавьте:
```javascript
QUIZZES['my-topic'] = {
    title: 'My Quiz',
    questions: [ /* вопросы */ ]
}
```
