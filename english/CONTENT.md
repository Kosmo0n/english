## 📈 Как система считает прогресс?

### Завершённая тема
```
percentage >= 60% → completedTopics[topicId] = true
```

### Слабая область
```
percentage < 60% → добавить в weakAreas
```

### Средний балл
```
averageScore = sum(все percentage) / количество квизов
```

### Прогресс класса
```
classProgress = (завершённые темы / всего тем) × 100%
```
