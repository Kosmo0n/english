# ⚡ БЫСТРЫЙ СТАРТ (60 секунд)

## Способ 1️⃣: САМЫЙ ПРОСТОЙ (Для всех)

### Windows/Mac/Linux - Одинаково:
1. **Найти** файл `index.html` в папке `gitkos`
2. **Двойной клик** или перетащить в браузер
3. **Готово!** ✅

---

## Способ 2️⃣: С ЛОКАЛЬНЫМ СЕРВЕРОМ

### 🪟 Windows

#### Способ A: Python (встроен)
```batch
# Открыть командную строку (Win+R), затем:
cd C:\Users\Мансур\Desktop\gitkos
py -m http.server 8000
```

Затем откройте в браузере: **http://localhost:8000**

#### Способ B: Node.js (если установлен)
```batch
# В папке gitkos:
npx http-server
```

Затем откройте: **http://localhost:8080**

---

## 🆘 Если не работает

### Ошибка: "Файл не найден"
```
✓ Проверьте что папка называется ровно "gitkos"
✓ Не используйте пробелы в названиях
✓ Убедитесь что это именно папка, а не архив
```

### Ошибка: "Стили не загружаются"
```
✓ Перезагрузите: Ctrl+F5 (очистить кэш)
✓ Откройте консоль: F12 → Network
✓ Проверьте что файлы загружаются
```

### Ошибка: "Квизы не работают"
```
✓ Откройте консоль: F12 → Console
✓ Ищите красные ошибки
✓ Проверьте что js/data файлы существуют
```
