## 💾 Сохранение данных

### Где хранятся данные?
**LocalStorage браузера** (на устройстве пользователя)
- Автоматическое сохранение
- Полная конфиденциальность
- Нет отправки на сервер

### Что сохраняется?
```javascript
{
  completedTopics: { /* завершённые темы */ },
  quizResults: [ /* результаты квизов */ ],
  weakAreas: [ /* области для повторения */ ]
}
```

Подробно → [CONTENT.md#-localstorage-схема](CONTENT.md)

## 🔧 Кастомизация

### Изменить цвета
Отредактируйте `css/styles.css`:
```css
:root {
    --primary: #YourColor;
    --accent: #YourColor;
}
```

### Добавить новую тему
Отредактируйте `js/data/topics.js`:
```javascript
TOPICS[7].push({
    id: 'my-topic',
    title: 'My Topic',
    description: '...',
    icon: '📚'
});
```

### Добавить квиз
Отредактируйте `js/data/quizzes.js`:
```javascript
QUIZZES['my-topic'] = {
    title: 'My Quiz',
    questions: [ /* вопросы */ ]
};
```

Подробно → [README.md#-кастомизация](README.md) и [SETUP.md](SETUP.md)
